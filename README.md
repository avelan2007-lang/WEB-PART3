## Project Overview
A five-page website for Greensleeves Children's Trust, a non-profit foster village in Brakfontein, East London. The website provides information about the organisation's history, programmes, events, and ways to get involved.

## Website Goals and Objectives
1. Increase awareness and visibility of the organisation.
2. Generate funding and support through donations and sponsorships.
3. Strengthen community engagement through volunteer registration.

## Key Features and Functionality
- Five responsive HTML pages.
- External CSS stylesheet with responsive design.
- Navigation menu on all pages.
- Contact and enquiry forms.
- Social media links for backup (Facebook, LinkedIn, ForGood, GlobalGiving).

## Sitemap
- index.html (Home)
- about.html (About Us)
- services.html (Our Programmes)
- enquiry.html (Get Involved)

## Part 1 Details
